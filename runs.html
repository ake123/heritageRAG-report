2  The two runs, explained

What each command did, and why the test run and the final run look so alike

In short. You ran the same study twice, plus the extra Sámi test. The test run (batch-pilot) only searched. The final run (final) searched in exactly the same way and asked an AI to write an answer for every search. The searches gave identical results in both runs. Then you made blank checking sheets for two people and ran the scoring. The scores are empty because nobody has filled in the sheets yet. That is expected.

The four commands

Step Command What it does Cost Status
1. Test run run_study_batch.R ... results/batch-pilot none Searches Finna in the three ways for all questions. No AI. A safe test run. Free Done
2. Final run run_study_batch.R ... results/final openai --demo The same searches, plus an AI answer for each search (3 per question). Also copies the results into the demo app. A small OpenAI bill Done
3. Make checking sheets annotation.R sheets results/final 2 Makes blank spreadsheets for two people to judge the records and the AI’s sentences, with the source of each item hidden. Free Done (157 records, 468 sentences per person)
4. Score the sheets annotation.R score results/final Reads the filled-in spreadsheets and calculates scores and agreement. Free Ran too early: sheets are still empty
5. Sámi test (extra) run_sami_sensitivity.R ... results/sami-sensitivity Runs all questions twice, back to back: search C with Finnish, Swedish and English thesaurus names, then with Northern Sámi names added. No AI. See Extra tests. Free Done (30 October 2026)

The searches were exactly the same. For all 39 searches, the number of matching records, the records kept, the number of institutions and the number of languages are identical between the two runs, which were 19 minutes apart.

This tells us two useful things:

  1. The search part is repeatable. Run twice with the same settings, it gives the same evidence. (Finna’s collections do change slowly over weeks and months, which is why every run records its date.)
  2. The final run is the one to report. It contains everything the test run has, plus the AI answers. Keep the test run as proof that the searches are stable.

Why the scores are empty

The score command reads the spreadsheets that the two checkers fill in. You ran it straight after making the blank sheets, so it found 0 judgements and every score came out empty (shown as “NA” in the files). Nothing is wrong: run it again once both people have finished. The Human checking page explains what they need to do. When the sheets are filled, that page shows the results automatically.

TipUpdating this report after a new run

Copy the new results into the report and render it again:

Rscript prepare_data.R ../heritageRAG/results/final ../heritageRAG/results/batch-pilot ../heritageRAG/results/sami-sensitivity
quarto render

The third folder (the Sámi test on Extra tests) is optional. To redo the analysis and the paper figures with a newer heritageRAG without searching again, first run Rscript scripts/refresh_analysis.R results/final in the heritageRAG folder. Every number and chart on these pages is recalculated from the files. Only the short notes in notes.csv are written by hand, so check those after a new run.
