Swedish-language theatre

How is Swedish-language theatre in Finland documented between 1850 and 1950?

Key words: Finland Swedes and theatre | Years: 1850-1950 | Asked in: English

What happened

  • No search found any records to keep (matching records in Finna: A 0, B 0, C 0).
  • No thesaurus concept was found for: Finland Swedes, so search C could not add official names for it.
  • Annif’s words added in search B: theatres.

No search found anything. Finland Swedes is not the thesaurus’s term: YSO calls the group Swedish-speaking Finns, which Annif did suggest, but it fitted neither key word. In the first run, Annif’s Finland was attached to Finland Swedes and the search drifted to any theatre in Finland; that rule is now fixed, and without it the everyday term finds nothing. Ask again with the thesaurus term as the key word, or keep this as a failure case: the researcher’s word and the catalogue’s word do not meet.
